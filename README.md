# Тест сервы

**Версия 2.6.1** — консольное управление сервоприводом через Arduino.

## Команды
- `угол [0-180]` — повернуть серву
- `тест серво` — автотест 0° → 90° → 180°
- `статус` — статистика
- `сохранить` — сохранить данные
- `выход` — выход

## Подключение
- Arduino на COM3–COM7
- Сервопривод на 9 пине
- Скорость 9600

## Установка
pip install pyserial
и остальные они будут указаны при запуске системы
